# 帧回调设备测试程序实现计划

目标：将 `frame-callback-test` 改为真实设备命令行轮询工具，保留原有自动回归。

设计：原程序移到 `frame-callback-selftest.c`，新设备入口使用公开 libmodbus API。
命令选择 tcp/rtu。TCP 默认 192.168.9.60:502；RTU 要求显式串口路径，
默认 9600/8/N/1；站地址默认 1（1..247，不使用无法回读的广播）。
采用重复的读区参数 `--read-coils/--read-discrete/--read-holding/--read-input A:N`，
写区参数 `--write-coils/--write-registers A:V[,V...]`；支持十进制或 0x 地址。
所有地址按 0 基协议地址处理，验证地址范围、数量及写值，不截断非法输入。
无读区参数时读保持寄存器 0:1；无写区参数时不写。输入点位按协议只读。
每轮读取所有读区，写入全部写区并立即对各写区回读比对。
`--cycles 0` 默认持续轮询，`--interval 1000` 毫秒，支持超时、帧开关参数。
信号仅设置退出标志，主循环清理连接；错误输出带操作和地址，有限轮询失败返回非零。
不自动操作用户实际设备；集成验证使用临时 TCP 服务和 Linux 伪终端。
