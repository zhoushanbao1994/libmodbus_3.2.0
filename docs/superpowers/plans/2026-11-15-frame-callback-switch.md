# 报文回调开关实现计划

目标：增加 `int modbus_set_frame_callback_enabled(modbus_t *ctx, int enabled)`，
独立暂停或恢复每个实例的完整 TX/RX 回调，并保留回调函数和用户数据。

设计：在私有实例结构中增加布尔开关，在统一通知入口检查。
开关默认 TRUE，以兼容已注册回调立即生效的行为；无回调时仍不输出。
0 关闭，非零开启；注册、替换及注销回调不改变开关。
NULL 实例返回 -1/EINVAL，成功返回 0，不修改 errno。
开关与该实例的通讯操作串行执行，不控制独立的 debug 输出。
既有回调生命周期规则继续适用，暂停不等于注销，不能因此释放 user_data。
